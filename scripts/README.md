# Scripts Dataproc (responsable : personne A)

À faire : scripts pour créer un cluster de 2, 4 ou 6 nœuds (même type de machine),
soumettre le job, récupérer les résultats, puis **supprimer le cluster**.

Règles de budget :
- toujours `--max-idle` à la création ;
- supprimer le cluster dès la fin du job ;
- limite de 32 vCPU au total par projet.
